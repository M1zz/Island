# Unknown Island — IslandCore 프로토타입

미지의 무인도 생존 게임의 **시뮬레이션 코어 + 텍스트 프로토타입 + 밸런싱 봇**입니다.
렌더링과 완전히 분리되어 있어서, 나중에 SpriteKit 씬은 `GameEngine`을 그대로 구동하면 됩니다.

## 실행

```bash
swift run island            # 텍스트로 직접 플레이 (일기: ~/.island/journal.json)
swift run island 42         # 시드 고정
swift run -c release island-sim 1000   # 봇 1,000판 밸런싱 리포트
swift test                  # 결정성·규칙·밸런스 밴드 테스트
```

## 맥 앱 (픽셀 게임)

`Island.xcodeproj` 를 열고 스킴 `IslandApp` 을 ⌘R 로 실행한다.

| 키 | 하는 일 |
|---|---|
| 방향키 / WASD | 걷기 |
| Space | 눈앞의 것에 행동 (야자에서 코코넛, 유목·나무에서 땔감, 덤불·고사리·바위 채집, 물가 낚시, 개울 물 긷기, 모닥불, 잠자리, 구름 낀 땅 탐험) |
| C | 제작 메뉴 (숫자키 1~8 로 고름) |
| M | 지도 (나무 2개로 직접 그려야 볼 수 있다) |
| P | 일시정지 |

- 섬은 화면 마흔네 개 너비다(끝에서 끝까지 걸어서 3분쯤). 섬 전체를 들고 있지 않고, 어느 지점이든 공식으로 물어서
  카메라 주변의 땅 조각만 그린다(`App/IslandMap.swift`). 발견하지 못한 지역은 구름으로 덮여 들어갈 수 없다.
- 섬은 가로 A~L, 세로 1~8 격자로 나뉘고, 왼쪽 아래에 지금 있는 칸(예: D6)이 늘 보인다. 지도는 정확한 위치 대신 그 칸만 표시한다.
- 지역은 도구가 있어야 열린다: 정글은 돌도끼, 능선은 밧줄, 정상은 횃불. 막힌 곳 앞에 서면 말풍선이 필요한 도구를 보여 준다.
- 배경음악과 효과음은 실행할 때 사각파·삼각파·노이즈로 합성한다(`App/Sound.swift`, 음원 파일 없음). 오른쪽 위 스피커 버튼으로 끈다.
- 나무는 사람 키의 열 배쯤 되는 거목이다. 줄기는 길을 막고, 나무 뒤로 걸어가면 나무가 비쳐 보인다.
- 화면에 글자가 없다. 상태·기술·구조 조건·가방·제작 메뉴·말풍선이 모두 그림과 게이지다(숫자와 키 이름만 남는다).
- 시간은 스스로 흐른다. 가만히 있어도 한 시간씩 지나고(엔진의 `.rest`), 행동은 걸리는 시간만큼 시계를 돌린다.
  18시가 되면 밤이 오고 잠든 뒤 아침에 깬다.
- 규칙은 전부 `IslandCore` 에 있고 `App/` 은 그리기와 조작만 한다. 그림은 `App/Art.swift` 에서 직접 찍거나(작은 것) 규칙으로 길러 낸 것(거목)이라 외부 에셋이 없다.
- 일기는 터미널 판과 같은 `~/.island/journal.json` 을 쓴다.
- 타깃 구성을 바꿀 때는 `project.yml` 을 고치고 `xcodegen generate` 로 다시 만든다.
  스킴 `island`(터미널 플레이), `island-sim`(봇 1,000판)도 같은 프로젝트에 있다.

## 구조

| 파일 | 역할 |
|---|---|
| `Balance.swift` | **모든 수치.** 밸런싱은 여기만 고친다 |
| `Model.swift` | 스킬·아이템·지역·레시피·행동 정의 |
| `GameEngine.swift` | 규칙 전부 (행동 → 결과, 하루 종료 처리) |
| `SkillSet.swift` | 사용 기반 숙련, 레벨 계산 |
| `Journal.swift` | 회차 간에 남는 지식 (스킬은 초기화) |
| `Bots.swift` | random / forager(한 분야 전문가) / planner(숙련자) |
| `RNG.swift` | 시드 고정 SplitMix64 — 같은 시드 = 같은 게임 |

## 핵심 규칙

컨셉은 **초 리얼리티**다. 규칙은 실제 무인도에서 벌어지는 일을 따른다.

- 물은 두 가지다. **깨끗한 물**(코코넛, 빗물)은 그냥 마셔도 되고, **날물**(개울)은 불과 토기가 있어 끓인 날이 아니면 탈이 날 수 있다
- 코코넛은 해변과 야자숲의 야자에 올라 딴다. 양이 적고 떨어져 다칠 수 있다(채집 숙련이 오르면 줄어든다)
- 비 오는 날은 그 자리에서 마셔 갈증이 풀린다. 담아 둘 토기가 있어야 깨끗한 물 3이 남는다
- 갈증과 허기는 깨어 있는 매 시간 줄어든다(하루 총량은 같다). 목이 마르면 가진 물을 그때 마신다. 깨끗한 물부터 마시고, 날물을 그냥 마시면 탈이 날 수 있다
- 불을 피웠고 토기가 있으면 가진 날물이 끓여져 깨끗한 물이 된다
- 깨어 있기만 해도 조금씩 지친다. 회복은 잠뿐이라, 일찍 자는 것이 유일한 휴식이다
- 몸의 수치는 수분, 허기, 체온, 스태미너 넷이고, 체력은 이 넷이 바닥나거나 다쳤을 때 깎이는 결과라 게이지가 없다(60 아래로 내려가면 화면 가장자리가 붉어진다)
- 체온은 비를 맞으면 시간마다, 밤에는 한꺼번에 떨어진다. 불과 움막이 밤 추위를 막고, 마른 날 낮에는 되돌아온다. 40 아래로 자면 떨다가 못 쉬고, 0 이면 저체온으로 체력이 깎인다
- 몸뚱이 하나로 떠밀려 왔다: 모자도 침구도 없고, 잠자리는 모래 위에 깐 야자 잎이다

- 하루 12시간. 피로 20당 다음 날 1시간 손실
- 구조 조건: 정상 발견 + 신호대 제작(제작 3) + 마른 나무 30 + 생존 2 → 신호 점화
- 21일차 폭풍 = 게임 오버
- XP = base × 새로움(×2) × 난이도(0.5~2) × 실패(×1.5) × 같은날반복(0.7ⁿ)
- 지역은 `difficulty - 1` 레벨부터 시도 가능 → 낮은 확률로 도전하고 실패하며 배움
- 지역 관문: 정글 ← 돌도끼(나무 2·섬유 2·돌 1), 능선 ← 밧줄(섬유 6, 제작 1), 정상 ← 횃불(마른 나무 2·섬유 2, 제작 1). 도구 없이는 탐험을 시도할 수 없다

## 현재 밸런스 (1,000판, Swift 와 Python 미러 결과 일치)

| 봇 | 구조 | 폭풍 | 사망 | 평균 구조일 |
|---|---|---|---|---|
| random (초보) | 0% | 94% | 6% (대부분 저체온) | – |
| forager (전문가) | 0% | 93% | 7% | – |
| planner (숙련자) | 41% | 56% | 2% | 19.0 |
| planner + 일기(베테랑) | 74% | 25% | 1% | 18.5 |

코코넛이 생기면서 아무것도 모르는 초보도 목말라 죽지는 않게 됐다(예전 39% 사망). 구조되지 못하는 것은 그대로다.

`Tools/balance-mirror/`는 Swift 없는 환경에서 수치를 돌리려고 만든 Python 미러입니다.
**기준은 Swift 코드**이고, 규칙을 바꾸면 미러는 버리거나 같이 고쳐야 합니다.
