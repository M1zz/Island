# Unknown Island — IslandCore 프로토타입

미지의 무인도 생존 게임의 **시뮬레이션 코어 + 텍스트 프로토타입 + 밸런싱 봇**입니다.
렌더링과 완전히 분리되어 있어서, 나중에 SpriteKit 씬은 `GameEngine`을 그대로 구동하면 됩니다.

## 실행

```bash
swift run island            # 텍스트로 직접 플레이 (일기: ~/.island/journal.json)
swift run island 42         # 시드 고정
swift run -c release island-sim 1000   # 봇 1,000판 밸런싱 리포트
swift test                  # 결정성·규칙·밸런스 밴드 테스트
```

## 맥 앱 (픽셀 게임)

`Island.xcodeproj` 를 열고 스킴 `IslandApp` 을 ⌘R 로 실행한다.

| 키 | 하는 일 |
|---|---|
| 방향키 / WASD | 걷기 |
| Space | 눈앞의 것에 행동 (나무·덤불·고사리·바위 채집, 물가 낚시, 개울 물 긷기, 모닥불, 잠자리, 안개 낀 땅 탐험) |
| C | 제작 메뉴 (숫자키로 고름) |
| M | 섬 전체 지도 |
| P | 일시정지 |

- 섬은 화면 여덟 개 너비이고 카메라가 캐릭터를 따라간다. 발견하지 못한 지역은 안개로 덮여 들어갈 수 없다.
- 시간은 스스로 흐른다. 가만히 있어도 한 시간씩 지나고(엔진의 `.rest`), 행동은 걸리는 시간만큼 시계를 돌린다.
  18시가 되면 밤이 오고 잠든 뒤 아침에 깬다.
- 규칙은 전부 `IslandCore` 에 있고 `App/` 은 그리기와 조작만 한다. 그림은 `App/Art.swift` 에 직접 찍은 것이라 외부 에셋이 없다.
- 일기는 터미널 판과 같은 `~/.island/journal.json` 을 쓴다.
- 타깃 구성을 바꿀 때는 `project.yml` 을 고치고 `xcodegen generate` 로 다시 만든다.
  스킴 `island`(터미널 플레이), `island-sim`(봇 1,000판)도 같은 프로젝트에 있다.

## 구조

| 파일 | 역할 |
|---|---|
| `Balance.swift` | **모든 수치.** 밸런싱은 여기만 고친다 |
| `Model.swift` | 스킬·아이템·지역·레시피·행동 정의 |
| `GameEngine.swift` | 규칙 전부 (행동 → 결과, 하루 종료 처리) |
| `SkillSet.swift` | 사용 기반 숙련, 레벨 계산 |
| `Journal.swift` | 회차 간에 남는 지식 (스킬은 초기화) |
| `Bots.swift` | random / forager(한 분야 전문가) / planner(숙련자) |
| `RNG.swift` | 시드 고정 SplitMix64 — 같은 시드 = 같은 게임 |

## 핵심 규칙

- 하루 12시간. 피로 20당 다음 날 1시간 손실
- 구조 조건: 정상 발견 + 신호대 제작(제작 3) + 마른 나무 30 + 생존 2 → 신호 점화
- 21일차 폭풍 = 게임 오버
- XP = base × 새로움(×2) × 난이도(0.5~2) × 실패(×1.5) × 같은날반복(0.7ⁿ)
- 지역은 `difficulty - 1` 레벨부터 시도 가능 → 낮은 확률로 도전하고 실패하며 배움
