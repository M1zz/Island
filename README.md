# Unknown Island — IslandCore 프로토타입

외계 행성 테라포밍 생존 게임의 **시뮬레이션 코어 + 텍스트 프로토타입 + 밸런싱 봇**입니다.
렌더링과 완전히 분리되어 있어서, 나중에 SpriteKit 씬은 `GameEngine`을 그대로 구동하면 됩니다.

## 실행

```bash
swift run island            # 텍스트로 직접 플레이 (일기: ~/.island/journal.json)
swift run island 42         # 시드 고정
swift run -c release island-sim 1000   # 봇 1,000판 밸런싱 리포트
swift test                  # 결정성·규칙·밸런스 밴드 테스트
```

## 맥 앱 (픽셀 게임)

> 규칙은 외계 행성으로 바뀌었고 그림은 옮기는 중이다. 주인공·식물·아이콘·오프닝에 무인도 시절 그림이 남아 있다.

`Island.xcodeproj` 를 열고 스킴 `IslandApp` 을 ⌘R 로 실행한다.

| 키 | 하는 일 |
|---|---|
| 방향키 / WASD | 걷기 |
| Space | 눈앞의 것에 행동 (숨주머니 따기, 바이오매스·섬유·광석·먹을 것 채집, 빙하에서 얼음 캐기, 버너 켜기, 잠자리, 안개 낀 땅 탐험) |
| C | 제작 메뉴 (숫자키 1~8 로 고름) |
| M | 지도 (나무 2개로 직접 그려야 볼 수 있다) |
| Tab | 모든 패널 보이기/숨기기 |
| P | 일시정지 |

- 실행하면 표류 경위가 먼저 나온다: 해 질 녘의 돛단배, 폭풍, 널빤지, 섬(`App/Intro.swift`). 아무 키나 누르면 건너뛴다.
- 시점은 화면 단위다. 걷는 동안 화면은 멈춰 있고, 가장자리를 넘으면 옆 화면으로 넘어간다.
- 궁금해서 가 보게 되는 것들이 있다: 모래톱 끝의 난파선, 정상으로 가는 동굴 입구, 좋은 자리 위를 도는 갈매기, 먼바다를 지나가는 배, 그리고 먼저 왔다가 나가지 못한 조난자의 유골(일기에 남은 실패한 회차마다 하나씩 늘어난다).
- 섬은 화면 마흔네 개 너비다(끝에서 끝까지 걸어서 3분쯤). 섬 전체를 들고 있지 않고, 어느 지점이든 공식으로 물어서
  카메라 주변의 땅 조각만 그린다(`App/IslandMap.swift`). 발견하지 못한 지역은 구름으로 덮여 들어갈 수 없다.
- 섬은 가로 A~L, 세로 1~8 격자로 나뉘고, 왼쪽 아래에 지금 있는 칸(예: D6)이 늘 보인다. 지도는 정확한 위치 대신 그 칸만 표시한다.
- 섬은 굴려서 나온 모양이 아니라 그려 놓은 모양이다: 북쪽의 산, 서쪽의 야자 반도, 동쪽의 강 골짜기, 남쪽 만과 그 앞 모래톱 끝의 난파선 섬.
- 지역 사이는 그냥 넘어갈 수 없다. 정글은 덤불 벽, 산은 절벽, 해변 양끝은 바위 줄기가 막고 있고, 벽마다 난 틈(관문)을 찾아야 한다.
  정글 관문은 돌도끼, 능선은 밧줄, 정상은 횃불이 있어야 열린다. 정글 관문은 야영지 바로 뒤에 있어 처음부터 보이고, 정상 관문은 산 반대편에 있다.
- 자원은 고르게 흩어져 있지 않고 자리가 있다: 난파선 섬의 유목, 갯벌의 조개, 폭포 아래의 돌, 정글 안 고사리 골, 곶의 야자 숲. 숲은 군락과 빈터로 나뉜다.
- 배경음악과 효과음은 실행할 때 사각파·삼각파·노이즈로 합성한다(`App/Sound.swift`, 음원 파일 없음). 오른쪽 위 스피커 버튼으로 끈다.
- 나무는 사람 키의 열 배쯤 되는 거목이다. 줄기는 길을 막고, 나무 뒤로 걸어가면 나무가 비쳐 보인다.
- 평소 화면에는 섬만 있다. 게이지는 위험해진 것만 뜨고, 가방은 내용이 바뀔 때, 달력은 날이 바뀔 때 잠깐 떴다 사라진다. 전부 보려면 Tab.
- 화면에 글자가 없다. 상태·기술·구조 조건·가방·제작 메뉴·말풍선이 모두 그림과 게이지다(숫자와 키 이름만 남는다).
- 시간은 스스로 흐른다. 가만히 있어도 한 시간씩 지나고(엔진의 `.rest`), 행동은 걸리는 시간만큼 시계를 돌린다.
  18시가 되면 밤이 오고 잠든 뒤 아침에 깬다.
- 규칙은 전부 `IslandCore` 에 있고 `App/` 은 그리기와 조작만 한다. 그림은 `App/Art.swift` 에서 직접 찍거나(작은 것) 규칙으로 길러 낸 것(거목)이라 외부 에셋이 없다.
- 일기는 터미널 판과 같은 `~/.island/journal.json` 을 쓴다.
- 타깃 구성을 바꿀 때는 `project.yml` 을 고치고 `xcodegen generate` 로 다시 만든다.
  스킴 `island`(터미널 플레이), `island-sim`(봇 1,000판)도 같은 프로젝트에 있다.

## 구조

| 파일 | 역할 |
|---|---|
| `Balance.swift` | **모든 수치.** 밸런싱은 여기만 고친다 |
| `Model.swift` | 스킬·아이템·지역·레시피·행동 정의 |
| `GameEngine.swift` | 규칙 전부 (행동 → 결과, 하루 종료 처리) |
| `SkillSet.swift` | 사용 기반 숙련, 레벨 계산 |
| `Journal.swift` | 회차 간에 남는 지식 (스킬은 초기화) |
| `Bots.swift` | random / forager(한 분야 전문가) / planner(숙련자) |
| `RNG.swift` | 시드 고정 SplitMix64 — 같은 시드 = 같은 게임 |

## 핵심 규칙

추락한 탐사선에서 혼자 살아남아, 겨울이 오기 전에 **행성을 숨 쉴 수 있는 곳으로 바꾸는** 게임이다.

- 몸의 수치는 산소, 허기, 체온, 스태미너 넷이다. 체력은 이 넷이 바닥나거나 다쳤을 때 깎이는 결과라 게이지가 없다
- 산소통은 깨어 있는 매 시간 줄고, 낮아지면 가진 공기 캔을 연다. 공기는 처음엔 **숨주머니 풀**에서만 얻는다(높이 달려 있어 떨어져 다칠 수 있다)
- 빙하에서 캔 **얼음**은 그대로는 쓸모없다. 전기분해기를 세우고 그날 버너를 켜야 공기가 된다
- 버너는 바이오매스를 태운다. 켠 날은 밤이 따뜻하고, 음식이 더 든든하고, 전기분해기가 돈다
- 광석은 제련기에서 금속이 되고, 금속으로 장치를 짓는다
- 체온은 가운데(50)가 정상이다. 폭풍과 밤은 내리고, 한낮의 트인 땅은 우주복을 달궈 올린다. 0 이면 저체온, 100 이면 일사병
- 지역 관문: 균류 숲 ← 절단기, 분화구 테두리 ← 줄, 분출구 ← 등
- **테라포밍**: 장치 셋을 순서대로 세운다. 가열기(착륙지, 하루 +4%) → 해빙기(빙하, +4%) → 파종기(분출구, +6%). 세운 장치는 매일 밤 행성을 돌린다
- 행성이 돌수록 산소가 덜 줄고, 밤이 덜 춥고, 먹을 것과 바이오매스가 더 자란다. 땅과 바다의 색도 녹슨 빛에서 푸른 빛으로 바뀐다
- 100% 가 되면 헬멧을 벗는다(승리). 24일째에 긴 겨울이 오면 끝이다
- XP = base × 새로움(×2) × 난이도(0.5~2) × 실패(×1.5) × 같은날반복(0.7ⁿ). 기술은 회차마다 초기화되고, 일기에 남은 지역 지식만 이어진다
